## 1. 原型选择

| 叙事目的 | 主原型 |
|---|---|
| 建立陌生空间、突出孤独尺度 | A 柱廊独行 |
| 表现队伍前进、朝圣或等级 | B 斜阶群像 |
| 表现同伴关系、停步眺望 | C 崖边眺望 |
| 第一次展示核心奇观 | D 瀑布奇观 |
| 表现旅程延续、多人同行 | E S形水庭 |
| 收尾、选择、抵达终点 | F 悬台终章 |
| 横向展示瀑布宫殿并保留独行叙事 | G 瀑边横廊独行 |
| 两人共同朝圣、向往同一目标 | H 中央云阶双人 |
| 表现无限回廊和连续空间 | I 弧形柱廊独行 |
| 入夜转折、独自面对命运目标 | J 月夜轴线栈道 |
| 用环境远景建立三人关系 | K 露台三人关系戏 |
| 用圆门、巨月、古松建立仙境意象 | L 圆月门群像框景 |
| 用连续廊桥和大队列收束天宫全景 | M 云海廊桥大队列 |
| 用透明悬台、巨型灵鱼深化奇境 | N 透明锦鲤悬台群像 |
| 用严格中轴建筑建立双人智性关系 | O 对称圆拱双人对弈 |
| 用横向宫城飞瀑建立双人冲突 | P 飞瀑天宫双人对峙 |

## 2. A 柱廊独行

**构图公式：** 左侧裁切基座＋重复巨柱＋下方极小独行者＋横向云海。

- 16:9，24–28mm，平视或轻微低机位，深景深。
- 左侧巨型基座约 30%；柱列占中右部并向中央偏右消失点收缩。
- 人物位于横向约 38%、纵向约 85%，高度 8%–12%，侧身行走。
- 建筑占 85% 以上，人物仅作尺度参照。
- 冷蓝阴影，左侧暖金边光，顶部浮雕可用暗金点亮。
- 视频：与人物平行的极慢侧移，或沿柱廊轻微前推；不可环绕。
- 常见失败：人物变大、柱子太细、柱列没有统一消失点、场景变成普通走廊。

## 3. B 斜阶群像

**构图公式：** 右下至上方的对角天阶＋三组小人物＋左侧云海留白＋暗色悬崖框景。

- 16:9，60–85mm，高位斜俯拍 30°–45°，不是垂直航拍。
- 阶梯从右下进入、向上方中央延伸，占画面 55%–65%。
- 左侧保留 30%–40% 云海；左边缘可加入悬崖和横伸古松。
- 7–12 人分三组递进。例：下方 1 人、中段 5 人、上方 3 人。
- 最近人物不超过 12%，最远人物约 4%–6%；全部背向或侧背向上行。
- 视频：沿天阶方向极慢推近或轻微升高，保持队形与阶梯对角线。
- 常见失败：人物整齐横排、队伍变军阵、阶梯变水平、镜头变 90° 航拍。

## 4. C 崖边眺望

**构图公式：** 左侧巨树框景＋中央偏左三人背影＋脚下断崖＋右侧云海目标。

- 16:9，35mm，固定大全景，平视至轻微俯视。
- 巨树占左侧 25%–30%，树枝横伸至中央上方，不遮挡人物。
- 正好三名成年人，位于中央偏左，高度约 15%–20%。
- 使用“深色—暖色—浅色”服装节奏；三人前后错开，共同望向右侧。
- 左上可放近处巨型宫墙，右侧放远方宫殿和云海留白。
- 视频：近乎静止，仅缓推 5% 或轻微向右漂移；风吹披帛提供画内运动。
- 常见失败：三人转头、增加第四人、树枝遮脸、画面变成普通山顶合影。

## 5. D 瀑布奇观

**构图公式：** 左侧巨殿＋中央偏右垂直瀑布分界＋建筑兽首喷流＋栏杆旁微小人物＋右侧云海。

- 16:9，35mm，固定中远景，深景深。
- 宫殿约占左侧 55%，云海约占右侧 40%。
- 主瀑布位于中央偏右，宽 8%–12%，从顶部贯穿到底部。
- 兽首是与基座融合的无生命建筑雕塑；喷流受重力影响并连续落下。
- 3–5 名人物位于平台远端，高度 3%–5%，一人可穿暖色。
- 视频：先由宫柱或兽首遮挡，缓慢右移揭示主瀑布与云海；只做一次揭示。
- 常见失败：把石雕变活龙、瀑布悬空中断、水像白布、人物抢占主体。

## 6. E S形水庭

**构图公式：** 右下S形雕花步道＋左下静水池＋中央偏左四人背影＋左上巨型画壁＋右侧云海。

- 16:9，28–35mm，轻微高角度固定大全景。
- 步道从右下进入，向中央弯曲，再转向中央偏左，形成连续 S 曲线。
- 栏杆沿外侧曲线缩小；水面位于步道内侧，反射低对比且轻微扭曲。
- 正好四名成年人，高度 7%–10%，前后错开，不整齐横排。
- 左上画壁或宫门占 35%–45%；右上保留干净天空。
- 视频：沿 S 曲线从后方缓慢跟进，人物速度一致，镜头不越过人物。
- 常见失败：步道变直、栏杆断裂、人数错误、画壁变广告屏、水面完美镜像。

## 7. F 悬台终章

**构图公式：** 左侧悬崖古松＋中央横向悬台＋单人背影＋正后方巨门＋下方云海。

- 16:9，60–85mm，平视至轻微高角度长焦远景。
- 悬崖占左侧 18%–22%；平台位于画面高度约 65%，横向伸出。
- 正好一名成年人，位于水平中央，高度 12%–16%，完全背对镜头。
- 巨门以人物为中心，约占画面高度 45%–55%；外围建筑层层后退。
- 云海占下方约 25%，右侧保留天空呼吸空间。
- 视频：极慢中心推近，推进 5%–10%，保持人物与巨门同轴，不环绕。
- 常见失败：出现第二人、巨门变普通房门、人物偏离中心、平台落在地面。

## 8. G 瀑边横廊独行

**构图公式：** 下方横向暗台＋左侧超框巨殿＋中央连续瀑布群＋暖色独行者＋右侧云海。

- 16:9，32–40mm，平视至轻微高机位，固定大全景，深景深。
- 暗色前景平台横贯底部 12%–16%；宫殿占左侧至中央约 60%，云海占右侧约 35%。
- 单人位于横向 38%–42%、纵向约 80%，高度 16%–19%，侧背向右行走；衣摆受风向和惯性共同影响。
- 主瀑布群位于中央至中央偏右，占宽度 25%–30%，从明确出水口连续落入云海。
- 可在左侧中景放 3–4 名低饱和配角作尺度参照，但不能出现第二名前景暖色主角。
- 视频：与人物同向极慢侧移，或由左侧巨柱遮挡后右移揭示瀑布；只选一种主运动。
- 常见失败：前景人物变大、出现第二个暖色主角、瀑布无出水口、龙首变活龙、宫殿与云海位置互换。

## 9. H 中央云阶双人

**构图公式：** 底部展开的中央云阶＋严格单点透视＋下方双人背影＋尽头轴线主殿＋左右云海。

- 16:9，50–70mm，人物后方轻微高机位，固定大远景，f/8。
- 云阶从底部近乎全宽进入，向横向 50%、纵向约 21% 的唯一消失点收束，占画面 50%–55%。
- 正好两名成年人位于下方中央，高度 10%–13%；一冷一暖、并肩但一人领先半步，共同背向上行。
- 主殿位于顶部中央，占宽度 35%–42%；入口、云阶中线与人物之间的视觉中线保持同轴。
- 左右云海共同占 45%–50%，栏杆间距随透视均匀缩小。
- 视频：沿云阶中线极慢推近或轻微升高，不越过人物，不改变两人左右关系。
- 常见失败：云阶变普通公路、人物增加、两人横向分散、主殿偏轴、左右栏杆使用不同消失点。

## 10. I 弧形柱廊独行

**构图公式：** 左侧开放云海＋右侧超框巨型柱廊＋右下弧形步道＋暖色独行者＋共同弯向左中部的重复结构。

- 16:9，24–28mm，平视至轻微高机位，固定大全景，f/8。
- 云海占左侧 40%–45%；柱廊占右侧 55%–60%，近处柱体、门墙与飞檐局部超框。
- 步道从右下进入，向横向约 38%、纵向约 43% 的消失区域平滑弯曲。
- 步道、栏杆、柱列、飞檐和地面色带必须共享同一弧线、缩短节奏与消失区域。
- 单人位于横向约 65%、纵向约 61%，高度 14%–17%，侧背向左前方行走；暖色衣摆拖向右后方。
- 视频：与人物平行沿弧线极慢跟移，镜头不越过人物，不把弧廊拉直。
- 常见失败：弧廊变直、屋檐和栏杆弯曲方向不同、人物走反方向、柱距忽大忽小、地面变完美镜面。

## 11. J 月夜轴线栈道

**构图公式：** 双侧暗景框景＋中央栈道单点透视＋轴线单人背影＋远方浮空主殿＋宫殿后方巨月。

- 16:9，60–70mm，平视至轻微高机位，固定大远景，f/8。
- 左右岩壁、松竹或门柱各占 14%–16%；中央栈道从底部 24% 宽度收束至横向 50%、纵向约 53%。
- 正好一名成年人位于水平中央，高度 17%–19%，完整背影；人物、栈道中线和主殿入口完全重合。
- 浮空主殿占顶部中央宽度约 42%；巨月位于宫殿后方中央偏右，占高度约 42%，被屋顶遮挡一部分。
- 冷月逆光勾勒人物与屋檐，宫殿暖金灯火作次级光源；低位雾不穿透人物或栏杆。
- 视频：极慢中心推近 5%–10%，保持巨月、主殿、人物同轴，不环绕。
- 常见失败：出现第二人、巨月跑到建筑前方或左侧、月亮变白盘、主殿偏轴、栈道斜出画面。

## 12. K 露台三人关系戏

**构图公式：** 右侧超框殿檐门廊＋底部斜向露台＋中央偏右三人三角互动＋左侧浮空巨殿＋左下云海。

- 16:9，32–40mm，平视至轻微高机位，固定远景，f/8。
- 右侧门廊占 32%–38% 并局部超框；左侧巨殿占 40%–45%；湿润露台占下方约 35%。
- 正好三名成年人位于横向 56%–72%、纵向 65%–80%，高度 14%–17%，形成松散三角而非横排。
- 使用“左冷、中央浅、右暖”色序；左侧人物略近，中央人物连接左右，右侧人物略后。
- 只设计一个克制互动手势，例如递信物、抬手阻止或低声说明；三人视线落在彼此之间，不看镜头。
- 视频：近乎固定或极慢推近；保持三人颜色、左右顺序、手势和前后关系连续。
- 常见失败：增加第四人、三人合影式并排、暖色人物跑到左侧、门内出现额外人物、地面反射完整复制人体。

## 13. L 圆月门群像框景

**构图公式：** 超大圆形洞门＋门内巨月云海＋右侧迎客松横枝＋右下四人背影＋下方暗色平台。

- 16:9，60–85mm，平视固定大远景，f/8。
- 圆门位于中央，占宽度 66%–72%、高度约 90%，顶部可局部超框；必须有真实厚度并与平台连接。
- 巨月位于圆门内中央偏右，占高度 58%–65%；松树主干从右侧进入，枝冠遮挡月体 15%–25%。
- 正好四名成年人集中在右下，横向 71%–81%、纵向 67%–86%，高度 16%–19%，采用紧凑错位队形。
- 门内云海占下半部，左中景放较大山峰、中央偏右放较小孤峰，建立不对称远近层次。
- 明确遮挡顺序：圆门边缘 → 迎客松 → 巨月 → 远山云海；人物站在门槛内前景，不与远景混层。
- 视频：极慢推近或轻微向右漂移，保持圆门形状、松枝遮挡比例和四人队形不变。
- 常见失败：圆门变发光传送门、月亮跑到门外或树前、树枝无主干、人物移到中央、出现第五人。

## 14. M 云海廊桥大队列

**构图公式：** 右上古松近殿框景＋右下队列起点＋三段连续 S 形廊桥＋左侧浮空主殿＋中央仙塔远城＋下方云海水庭。

- 16:9，45–60mm，高位斜俯拍 25°–35°，固定大远景，f/8；不是垂直航拍。
- 古松与近殿占右侧及顶部 25%–30%；左侧主殿占 22%–28%；云海水庭占中央及下方 35%–45%。
- 廊桥从右下进入，经中央拱桥转折，再延伸至中上部远城；桥面、栏杆和人流共享同一连续 S 形路径。
- 约 50–100 名成年人分成近、中、远三组；全部沿同一方向行进，以白、灰、淡青为主，可放 2–4 名暖色礼官。
- 最近人物高度约 4%–7%，最远人物约 1%–3%；不描写面孔，人物始终位于桥内。
- 中央仙塔与远方宫城逐级缩小；左下可加悬崖瀑布，右下可加暗色水庭或极小舟夫点景。
- 视频：沿桥梁方向极慢前推 5%–10%，保持三组密度、共同方向和桥内边界；不越过近景队列。
- 常见失败：桥梁变直或断裂、三段路径不连接、队列成为军阵、人物漂浮云中、近景框景左右互换。

## 15. N 透明锦鲤悬台群像

**构图公式：** 右侧超框层叠宫殿＋向左伸出的透明悬空天池＋三至五人背影＋水下巨型锦鲤＋中央轴线天城＋左侧浮岛云海。

- 16:9，60–70mm，平视至轻微高机位，固定大远景，f/8。
- 右侧宫殿占 32%–38%；悬空水台位于画面高度 66%–75%，向左伸出约 27%–32% 画宽，并与宫殿结构连接。
- 3–5 名成年人位于水台远端，高度 9%–12%，采用两前两后或浅色群像＋一名暖色人物的错位队形。
- 透明水台必须有承重框架、透明侧壁、透明底部、水平水面和完整水体边界。
- 约 5–9 条巨型锦鲤分近、中、远三层，完全浸没在水中；写水下折射、鳞片高光、身体阴影和互相遮挡。
- 中央天城占宽度 55%–65%，主殿保持视觉轴线；左侧浮岛、悬垂巨柱和云海建立第二层尺度。
- 视频：仅沿水台方向极慢前推；人物、侧壁、水面和鱼群产生一致视差，鱼不得离开水体。
- 常见失败：鱼飞入云海、悬台无承重、变现代鱼缸或泳池、人物遮挡远城、锦鲤数量失控或融合。

## 16. O 对称圆拱双人对弈

**构图公式：** 顶部弧形穹顶＋左右鎏金巨柱＋中央实体圆拱门＋门内浮岛飞瀑＋下方中轴棋案＋左右双人对弈。

- 16:9，60–70mm，正面平视固定大全景，f/8，严格双边对称。
- 圆门位于中央，占宽度 48%–52%、高度 58%–64%；必须有厚度、内外边缘和与地面的连接结构，不是传送门。
- 唯一中轴线依次贯穿穹顶最高点、圆门圆心、门外主瀑布、棋盘中心和地面中心线。
- 正好两名成年人位于棋案左右两端，高度 9%–12%；左侧身体朝右，右侧身体朝左，彼此相对、不看镜头。
- 左右主柱、帷幕和栏杆保持建筑对称；左右古松只做视觉平衡，不复制镜像。
- 湿润地面仅反射低对比、轻微破碎的柱光与人物轮廓。
- 视频：只沿中轴极慢推近 5%–8%，保持圆门、飞瀑、棋盘与地面中心线共轴。
- 常见失败：圆门变椭圆或发光光环、双人坐在棋案同侧、出现第三人、中轴错位、左右树木复制粘贴。

## 17. P 飞瀑天宫双人对峙

**构图公式：** 右侧超框暗色重檐＋底部湿润露台＋中央偏右暖冷双人＋中央宽幅飞瀑群＋左上横向悬空宫城＋下方云海。

- 16:9，35–40mm，平视至轻微高机位，固定大远景，f/8。
- 右侧近殿占 35%–40% 并局部超框；湿润露台占底部 22%–26%；悬空宫城横跨左上至中央，占宽度 65%–72%。
- 正好两名成年人位于横向约 51%–64%、纵向约 72%–91%，高度 15%–18%；左暖右冷，彼此相隔约一个半身位。
- 双人以侧背影面对彼此，锁定颜色、左右顺序和一个克制动作；不表现正脸，不设计连续打斗。
- 飞瀑群位于中央偏左至中央，占宽度 25%–30%，从明确出水边缘连续落入云海；后方可见巨型支撑柱。
- 云海占中央下方 35%–40%；左下古松或远宫只做小面积点景。
- 视频：固定或沿露台微推 5%–8%，保持两人间距、颜色和单一手势；瀑布连续，宫城不漂移。
- 常见失败：人物放大抢占主体、红黑位置互换、增加第三人、瀑布变细线或白布、右侧框景消失。

## 18. 系列统一规则

同一系列跨原型时固定以下锚点：

- 16:9、24fps 电影瞬间感、低饱和暖金与冷青灰。
- 东方巨构采用重复飞檐、斗拱、石雕、巨柱和局部超框。
- 云海具有体积、阴影与空气透视，地平线稳定。
- 真人实景、自然比例、完整服装、克制动作。
- 真实石材、木材、金属、水体和风向；避免塑料 CGI 感。
- 圆门、门廊、古松、天体和人物重叠时，显式写出近景到远景的遮挡顺序。
- 中央轴线镜头保持引导结构、人物、建筑入口和天体中心的对齐；弧形镜头保持所有重复结构共享同一弧线。
- 湿润地面只保留低对比、轻微扭曲的反射；不复制完整人物。
- 无文字、无字幕、无水印、无 logo。
